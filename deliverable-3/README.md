## Open decisions

1. **How many items target naming.** Only item 5 in each week is naming-sensitive; items 1–4 and 6 are controls that rest on lines identical in A and B. This keeps every item answerable from Version A, as A2 requires, but means the five-item treatment-minus-baseline difference will be driven mostly by one item. A descriptive "specificity" tick on items 4 and 5 records when an answer uses Version B's names. If you want more sensitivity, the cost is an item Version A can only partly answer.
2. **Ten-need overall-mark rule.** Raphael to choose Rule 1 or Rule 2 before seeing any sheets. Rule 1 (best available source) gives 3 D / 7 P / 0 N for D1's final ten; Rule 2 (person-sourced needs count as N) gives 3 D / 4 P / 3 N. Choose on meaning, not on the mix.
3. **Which report the think-aloud uses.** The protocol uses report 2, which the counterbalancing splits 3 baseline / 3 treatment over R01–R06.
4. **Withdrawal deadline and data retention dates** in the consent form (proposed: 1 Nov 2026 for withdrawal).
5. **Participant floor (decided).** A2 says both "The floor is five of each" and "below five, think-alouds run first and the quantitative arm is descriptive". Decided by Raphael, 14 Oct 2026: **five readers in total**. The floor is met once R05 has finished (R01 to R04 cover all four sequences, R05 repeats S2); the quantitative arm runs on those five or more, and the pilot never counts. Below five, A2's fallback applies: think-alouds run first and the quantitative arm is reported as descriptive only. D5 points to this decision (`deliverable-5/README.md`).
