## Open decisions

1. **How many items target naming.** Only item 5 in each week is naming-sensitive; items 1–4 and 6 are controls that rest on lines identical in A and B. This keeps every item answerable from Version A, as A2 requires, but means the five-item treatment-minus-baseline difference will be driven mostly by one item. A descriptive "specificity" tick on items 4 and 5 records when an answer uses Version B's names. If you want more sensitivity, the cost is an item Version A can only partly answer.
2. **Ten-need overall-mark rule.** Rule 1 (best available source) gives 4 D / 6 P / 0 N for the provisional ten; Rule 2 (person-sourced needs count as N) gives 4 D / 3 P / 3 N. Choose on meaning, not on the mix.
3. **Which report the think-aloud uses.** The protocol uses report 2, which the counterbalancing splits 3 baseline / 3 treatment over R01–R06.
4. **Withdrawal deadline and data retention dates** in the consent form (proposed: 1 Nov 2026 for withdrawal).
5. **Participant floor (not yet decided).** A2 says both "The floor is five of each" and "below five, think-alouds run first and the quantitative arm is descriptive". **Raphael to decide: five readers in total, or five per report version.** If *five readers in total*: the floor is met after R05 (R01 to R04 cover all four sequences, R05 repeats S2), the quantitative arm runs on those five or more, and the pilot never counts. If *five per report version*, counted as readers whose first report is that version: that needs ten readers (five starting with A, five with B), and R01 to R08 give only four of each, so two more readers must be recruited. Until decided, fewer readers than the floor means think-alouds run first and the quantitative arm is reported as descriptive only. D5 states the same decision in one place (`deliverable-5/README.md`, open questions) and its fallback rule points to it.
