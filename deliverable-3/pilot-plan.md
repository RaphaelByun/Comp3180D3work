## What the pilot checks

| Check | How | Pass mark |
| --- | --- | --- |
| Timing per block | Clock times on the note sheet | Brief ≤ 5 min; each report block ≤ 12 min; sheet ≤ 6 min; think-aloud + follow-up ≤ 10 min; whole session ≤ 45 min |
| Item ambiguity | After each report block, ask: **"Was any question unclear, or could it be read two ways?"** Note the answer. Then score P0's sheets with the key. | Every P0 answer can be scored by a rule in `answer-key-and-scoring.md` without a judgement call |
| Ceiling and floor | P0's scores, Raphael's desk-run times | No item answered right in under 20 seconds by both P0 and Raphael, and no item P0 cannot start at all (see decision rules: one pilot is weak evidence) |
| Unanswerable item | P0's item 6 codes | Note only; one person cannot show whether it catches over-claiming |
| Ten-need sheet clarity | After the sheet, ask: **"Was anything on that sheet unclear? Did the three boxes make sense?"** Also read the "Anything unclear?" line. | P0 can say in their own words what T, R and U mean and what "Partly" means |
| Scenario and terms | Note every term P0 asks about | No question about a term the scenario already defines |
| Think-aloud | Count prods and long silences | P0 talks for most of the 6 minutes with ≤ 4 prods |
| Follow-up selection | Time to pick the three needs during the 34–35 min gap | Done within one minute |
| Second scorer | One other person scores P0's item sheets with the key, blind | Same score on every item, or a new rule is written |

## Decision rules for revising after the pilot

1. **Keep slots matched.** Any change to an item in one week is mirrored in the other week's same slot (same Endsley level, same question shape), unless the change fixes a fact that exists in only one week.
2. **Faults are always fixed:** a fixed answer that the report does not support, a question Version A cannot answer, or a wording P0 read two ways. Fix, re-verify against the report lines, log.
3. **Timing.** If a report block runs over 12 minutes, first shorten question wording, then allow 13 minutes per report and take a minute from the think-aloud (A2 total stays 45). Do not drop an item: the six-item structure is the A2 success measure.
4. **Ceiling or floor from one person is a flag, not a verdict.** Change an item for difficulty only if P0 **and** Raphael's desk run agree it is trivial or impossible. Otherwise keep it and watch R01–R02.
5. **New correct answers.** If P0 gives a defensible answer the key did not foresee, add it to the accepted variants. Do not reword the question for it unless rule 2 applies.
6. **Freeze after the pilot.** Once R01's session starts, items, key, sheet and script do not change. A fault found later is logged and reported as a limitation; the item may be dropped from the analysis for all readers, never changed for some.
7. **Sheet changes** follow the same rules. Swapping a need is allowed only to apply D1's final top ten, and must happen before R01.
