## The one judgment call: how "and N more" counts unidentified scripts

Rows 19, 23 and 27 are right only if script guids that do not resolve in `guids.txt` (fe87c0e1, f4688fdb, 4e29b1a8, 30649d3a, all Unity UI package components) are pooled into one "unidentified script" kind. The page uses that pooling itself (row 29 says "an unidentified script" for what is three unresolved guids on the added side), both earlier scorers used it, and the repaired page never states it. If the pass rule is applied with every script counted separately by guid, the counts become: row 19 added 16 kinds (page 13), row 23 removed 7 (page 5), row 27 added 6 (page 5), and these three would be contradicted. The unchanged row 29 (added side 7 kinds by guid against 5 on the page) would be contradicted by the same rule, and any other row with unresolved scripts would need rechecking. I scored them S because the claim wording does not say "by guid", the diff does not contradict the pooled reading, and the count is exact under the page's own convention. The fix, if wanted, is one line on the page ("scripts not found in the project are counted as one") or listing the unresolved scripts separately.
